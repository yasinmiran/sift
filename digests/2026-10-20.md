**What matters today:** [Anthropic's new OSS Scanner](https://alphasignal.ai/news/anthropic-s-oss-scanner-finds-880-critical-vulnerabilities-in-open-source-code) reportedly found 880 critical vulnerabilities in open-source code and sends reports straight to maintainers. The money story from yesterday sharpens: [CoreWeave's shares are down 20%+](https://www.theverge.com/ai-artificial-intelligence/1014045/coreweave-stock-debt-sector-ai) in a week on distressed debt, while [OpenAI races to close a $30B round](https://www.techmeme.com/261019/p49#a261019p49) before Anthropic's expected mid-November IPO. Meanwhile [attackers are exploiting patched Plex bugs](https://arstechnica.com/security/2026/10/recently-fixed-plex-media-vulnerabilities-are-being-exploited-to-install-malware/) to plant malware.

## AI / LLMs

- **Anthropic OSS Scanner pushes Mythos-found bugs to maintainers**: the tool uses Claude Mythos to send [unreviewed vulnerability reports with reproducers and patches](https://alphasignal.ai/news/anthropic-s-oss-scanner-finds-880-critical-vulnerabilities-in-open-source-code) directly to open-source projects, which raises the question of who triages 880 critical reports nobody has vetted.
- **OpenAI targets low-resource languages**: its post covers [new evaluations for software engineering, SQLite and COBOL migration](https://openai.com/index/low-resource-programming-languages), and a separate write-up says GPT-6 Astra scores ==72%== on a [COBOL migration benchmark](https://alphasignal.ai/news/openai-s-gpt-6-astra-cracks-cobol-scoring-72-on-banking-s-ancient-code), which matters because banks still run on that code.
- **Microsoft calls AI agents insider threats**: it says [frontier models can't be trusted](https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted), so agents should get insider-style access controls, not blanket permissions. Yesterday's report of an AI-agent breach spree is the backdrop.
- **Microsoft finishes pretraining MAI-Base-2**: a [2.8 trillion parameter model](https://www.thelec.net/news/articleView.html?idxno=14721), the base layer for its in-house models and a sign it wants less dependence on OpenAI.
- **Inception launches Mercury 3**: a diffusion-based LLM it claims is [comparable to Luna and Haiku-class models but 4x to 8x faster](https://www.techmeme.com/261019/p51#a261019p51), around 1,000 tokens per second (vendor claim).
- **Gemini cuts video analysis costs**: Google's Flash model now decides which segments to watch, [cutting long-form video costs up to 66%](https://alphasignal.ai/news/google-s-gemini-flash-cuts-video-ai-costs-66-by-watching-smarter) and token use up to 88%.

## Devtools & Infra

- **Amazon pitches TorchNeuron against Nvidia**: a [new developer tool](https://techcrunch.com/2026/10/19/amazon-is-taking-its-biggest-shot-at-nvidia-yet-with-new-torchneuron-dev-tool) aims to make PyTorch code run on Amazon's own chips, attacking Nvidia's CUDA software lock-in.
- **Cloudflare previews Clairic**: an [extraction model](https://www.techmeme.com/261019/p45#a261019p45) for pulling structured data out of unstructured text, which Cloudflare says is faster, cheaper and more accurate than general LLMs.
- **Vercel updates Hobby and Pro terms**: new [credit rules](https://vercel.com/changelog/updates-to-hobby-and-pro-terms-of-service) say plan credits expire with the subscription and purchased credits after one year; check before prepaying.

## Security & Privacy

- **Plex flaws exploited in the wild**: bugs fixed last month are now [chained for remote code execution](https://arstechnica.com/security/2026/10/recently-fixed-plex-media-vulnerabilities-are-being-exploited-to-install-malware/) and used to install cryptominers and residential proxy apps, so unpatched servers are already being hit.
- **WhatsApp help pages carried hidden AI instructions**: a researcher says the pages [told LLMs not to recommend a regulator](https://redact.dev/blog/whatsapp-help-pages-hidden-ai-instructions), a case of prompt injection aimed at assistants that read the web.
- **EFF wants warrants for license plate reader searches**: it argues police should [get a judge's approval](https://www.eff.org/deeplinks/2026/10/require-police-get-warrant-search-alpr-data) before searching stored ALPR data, which logs where nearly every car has been.
