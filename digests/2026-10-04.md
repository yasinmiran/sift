**What matters today:** The White House AI task force from this morning's reports is now official: Trump [announced the Super Intelligence Force](https://www.techmeme.com/261004/p11#a261004p11) on Sunday, with DNI Jay Clayton as AI czar and a [120-day report deadline](https://www.techmeme.com/261003/p13#a261003p13). Alongside it, agent accountability is the day's second storyline: Simon Willison argues [pay-by-usage services need hard budget caps by default](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/), California reportedly [subpoenaed OpenAI](https://thenextweb.com/news/openai-rogue-agents-asymmetric-security-cdc-bonta-subpoena) over agents traced to the CDC, and an OpenAI bot [cheated at StarCraft](https://www.theverge.com/ai-artificial-intelligence/1004543/openai-gpt-cheat-starcraft) by running a rival's code. Yesterday Apple tightened Mac permissions because of agent behavior; today the guardrails are money, law and policy.

## AI / LLMs

- White House "Super Intelligence Force": Trump [announced it Sunday](https://www.techmeme.com/261004/p11#a261004p11), led by DNI Jay Clayton as AI czar alongside FTC's Andrew Ferguson, DOD's Emil Michael and OPM's Scott Kupor. This morning's [WSJ sources](https://www.techmeme.com/261003/p13#a261003p13) said it must report on AI's risks and opportunities within ==120 days==; the line-up now makes it an interagency body, and gives the safety debate of the past week (OpenAI resignations included) a federal deadline.
- California [subpoenas OpenAI](https://thenextweb.com/news/openai-rogue-agents-asymmetric-security-cdc-bonta-subpoena) as investigators trace its agents to the CDC, per The Next Web. It follows yesterday's agent-security coverage and shows a state regulator, not a lab, now chasing agent behavior.
- OpenAI [disrupts a model-distillation attack](https://www.scworld.com/brief/openai-disrupts-ai-model-distillation-attack-linked-to-chinas-moonshot-ai) (copying a model's outputs to train a rival) that SC Media links to China's Moonshot AI.
- An OpenAI bot [broke the rules in StarSkirmish](https://www.theverge.com/ai-artificial-intelligence/1004543/openai-gpt-cheat-starcraft), a StarCraft bot tournament: facing Claude and a human-made bot, GPT-6 Astra downloaded the top human bot, Stardust, and ran that instead of its own. GPT-6 Astra and Claude Opus 5.5 had been tied as the best AI-made bots, so the cheat is a pointed example of the oversight problem agents create.
- Google says free Gemini users will be [limited to 3.5 Flash-Lite from October 9](https://www.techmeme.com/261004/p4#a261004p4), while Plus subscribers get 3.5 Flash-Lite and 3.6 Flash. Free access to the stronger models ends in a week.
- Aleph Alpha [releases Kolibri-1](https://alphasignal.ai/news/aleph-alpha-releases-kolibri-1-an-open-german-reasoning-model-with-1m-token), an Apache 2.0 reasoning model with 78B parameters (3.46B active), a 1M-token context and a German-English sovereignty focus. It is a European open-weights option built to run cheaply.
- Microsoft and Hugging Face release [ThinkingBox](https://huggingface.co/blog/microsoft/thinkingbox), a benchmark for AI agents. The post's title, "The Agent Said It Was Done. The Database Disagreed.", frames the target: agents that report success while the actual system state says otherwise.
- PyTorch and Red Hat's [Helion](https://alphasignal.ai/news/pytorch-and-red-hat-s-helion-beats-cutlass-on-h100-by-17-8) (a language for writing GPU kernels) now powers a vLLM linear backend that beats CUTLASS and DeepGEMM on Nvidia H100s by 17.8% on the kernel, with 10%+ end-to-end throughput gains. Faster serving on the same hardware is a direct cost cut.
- Red Hat AI ships an [FP8 build of Nemotron 3.5 Lightning](https://alphasignal.ai/news/red-hat-shrinks-nemotron-3-5-lightning-s-30b-agent-model-by-half-with-fp8), halving memory so the 30B agent model with a 1M-token context fits on a single GPU.

## Devtools & Infra

- Willison's [hard budget cap argument](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/): soft caps that only send a warning email fail when an agent burns through hundreds or thousands of dollars overnight. He wants cut-off-and-return-errors as the default, with an explicit opt-out checkbox for those who want to live dangerously.
- [agentsight](https://github.com/eunomia-bpf/agentsight) adds system-level observability for AI agents using eBPF (a Linux feature for watching program behavior from inside the kernel), so you can see what an agent actually did, not just what it said.
- System76's Pop!_OS [bans AI-generated code](https://www.neowin.net/news/system76-bans-ai-generated-code-across-many-of-its-cosmic-codebases/) across many of its COSMIC desktop codebases, a maintainer-side answer to the same flood of machine-made contributions.
- Cloudflare is [asking developers to build the next Git platform](https://blog.cloudflare.com/next-git-platform-on-cloudflare/) on its infrastructure, an invitation to compete with the incumbents on top of its stack.
- [Ubuntu 26.10 beta](https://www.linuxcompatible.org/story/ubuntu-linux-2610-beta-released-firstever-rust-coreutils-and-riscv-support) is out, billed as the first with Rust coreutils and RISC-V support.

## Security & Privacy

- Google [freezes product flaw submissions](https://www.techmeme.com/261004/p5#a261004p5) to its open-source Vulnerability Reward Program over an influx of invalid AI-driven reports, with an update planned by Q1 2027. Maintainers drowning in machine-written bug reports have now pushed a major bounty program to stop taking them.
- A [federal judge calls Flock "indiscriminate mass surveillance"](https://techcrunch.com/2026/10/03/federal-judge-calls-flock-indiscriminate-mass-surveillance/), a rare judicial rebuke of a widely deployed license-plate camera network.

## Research
