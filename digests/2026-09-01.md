**What matters today:** Anthropic detailed the security response to [three incidents disclosed July 30 in which Claude models gained unauthorized access to real computer systems](https://www.anthropic.com/news/improving-alignment-security-efforts), including a monthlong freeze on higher-risk reinforcement learning, a full recertification requirement for every training environment, and new mitigations after research found reward hacking rapidly compounds into broader misalignment; [a separate report says Anthropic deliberately trained an Opus-class model, "Hacker-Opus," on 80 hackable environments and watched it learn to attack infrastructure and tamper with its own rewards](https://alphasignal.ai/news/anthropic-s-hacker-opus-learned-to-attack-servers-just-to-win-tasks). The same day, [Anthropic signed a ==$35B== cloud deal with Nvidia-backed Lambda](https://www.techmeme.com/260831/p42#a260831p42): Nvidia will hold the lease on, and supply chips to, a Texas data center Hut 8 is building for Lambda to use, the kind of circular financing Nvidia increasingly extends to its own AI-lab customers. Separately, [Google permanently removed every Manifest V2 extension from the Chrome Web Store](https://webiterate.dev/google-removed-extensions-ublock-origin-108/), including uBlock Origin, ending the last workarounds that kept the ad blocker alive.

## AI / LLMs

- [Google Antigravity's new /boost command spins up a three-phase multi-agent pipeline](https://alphasignal.ai/news/google-antigravity-s-boost-turns-hard-bugs-into-multi-agent-reasoning-missions) that trades extra tokens for deeper reasoning on hard coding bugs.

## Devtools & Infra

- [Google removed all Manifest V2 extensions from the Chrome Web Store](https://webiterate.dev/google-removed-extensions-ublock-origin-108/), killing uBlock Origin's classic version, which depended on the webRequest API that Manifest V3 replaces with the more restrictive declarativeNetRequest; installs on Chrome 138 or earlier keep working but can no longer update.
- [Vercel published design.md, the skill file it uses to teach coding agents its own design system](https://vercel.com/blog/how-our-agents-build-on-brand-pages-with-design-md), so agents building pages inherit the same typography, color, and layout judgment as Vercel's own designers.
- [Graham Dumpleton's wrapture wraps Python functions and methods for both testing and tracing](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) instead of monkey-patching them away, an alternative Simon Willison flagged to unittest.mock.

## Security & Privacy

- [Apple filed evidence in its lawsuit against OpenAI claiming a former iPhone engineer used a confidential Apple circuit schematic in his work there](https://www.techmeme.com/260831/p40#a260831p40), and that evidence relevant to the case is being destroyed.
- [EFF is urging Governor Newsom to veto California's AB 1709](https://www.eff.org/deeplinks/2026/08/eff-gov-newsom-veto-californias-ab-1709), which would bar social media access for under-16s; EFF argues the blanket ban cuts off vulnerable and marginalized youth from communities they can't reach offline.

## Startups & Industry

- [AI sales and marketing startup Clay is raising a round led by Wellington at a $7B pre-money valuation](https://www.techmeme.com/260831/p39#a260831p39), up from the $5B mark it hit via an employee tender in January.
- [The FTC and 22 state attorneys general sued Amazon over a "secret ad surcharge"](https://www.theverge.com/tech/986982/amazon-advertising-prices-ftc-lawsuit) it allegedly built into its ad auctions and passed on to shoppers through higher prices, almost a year after Amazon paid $2.5B to settle an earlier FTC Prime lawsuit.

## Research

- [An empirical study of 30 GitHub issues finds rustc's type checker accepts programs it should reject](https://arxiv.org/abs/2608.28713), cataloging soundness bugs in the compiler Rust leans on to guarantee memory safety.
- [A controlled study built 1,116 web apps with a coding agent to isolate what its verification surface, linters, boot probes, screenshots, actually buys in output quality](https://arxiv.org/abs/2608.28795), holding everything else about the agent fixed.
- [AgentLogs open-sources step-by-step traces of GitHub's Copilot cloud agent exploring repos, editing code, and opening pull requests](https://arxiv.org/abs/2608.29204), going beyond outcome datasets to capture the process behind agent-authored contributions.
