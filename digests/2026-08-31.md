**What matters today:** [Over 12TB of Steam's old "Steam2" content servers leaked](https://arstechnica.com/gaming/2026/08/a-12tb-steam-teraleak-spills-more-than-a-decade-of-lost-pc-gaming-history/), covering every build uploaded between 2003 and 2013, including [abandoned Half-Life 2: Episode 3 assets and cut Portal 2 content](https://www.theverge.com/games/986552/12tb-steam-leak-half-life-2-episode-3). ## Research

- [ROPE proposes routing agent tool calls through origin-tagged policy checks to block indirect prompt injection](https://arxiv.org/abs/2608.27496), addressing cases where a malicious instruction only reveals itself once tool parameters are set at runtime, past where static screening can catch it.
- [ContextLeak formalizes how a malicious tool can exfiltrate an LLM agent's runtime context](https://arxiv.org/abs/2608.27800): the user's prompt, its execution trajectory, even its tool list, by getting the agent to pass that context as tool input, the step prior work had mostly skipped over.
- [A mechanistic-interpretability study traces the internal circuits a safety-aligned LLM uses when it gets jailbroken](https://arxiv.org/abs/2608.27504), isolating the subnetworks in Llama-2-7B-chat that generate compliant responses to adversarial prompts.
